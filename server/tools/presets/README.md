Snapshots of the stream equalizer (settings + measured speaker correction).

- `best-2026-10-27.json` — the setting the owner found to play best before the bass-priority limiter existed.
- `variant-A.json` — the same with the bass protection off (bass may use 70 % of the amplifier's range).
- `variant-B.json` — variant A plus the transient "punch" at 60 %.

To use one: copy it to `~/.jarvis_stream_presets/<best|A|B>.json` and press its button on the equalizer page.
