# Удалённый доступ к дому (Tailscale)

Зачем: когда ноутбук разработки не дома (школа и т. п.), до Home Assistant, сервера-аддона и
колонки не достучаться — у них адреса домашней сети 192.168.178.x. Tailscale делает свою
маленькую частную сеть поверх интернета: ноутбук и HA видят друг друга, где бы ни были.
Ничего не открывается наружу, бесплатно для личного пользования.

## Один раз, дома (≈10 минут)

**1. Home Assistant.** Настройки → Дополнения → Магазин дополнений → найти **Tailscale** →
Установить. На вкладке «Информация»: включить «Запускать при загрузке» и «Сторожевой таймер»
→ Запустить → **Открыть веб-интерфейс** → войти (Google, Microsoft или GitHub — какой удобнее)
→ подтвердить устройство. На странице admin.tailscale.com в списке появится `homeassistant` с
адресом вида `100.x.y.z`.

**2. Ноутбук.** Поставить Tailscale для Windows с tailscale.com/download → войти тем же
аккаунтом. Проверка: `ping homeassistant` отвечает.

**3. Сказать Claude.** Он поменяет в `server/.env` строку `JARVIS_SERVER=192.168.178.86` на
адрес из Tailscale (`homeassistant` или `100.x.y.z`) — по ней же работают `tools/send.py`,
программа для ПК и выкладка аддона (`\\<JARVIS_SERVER>\addons\jarvis`). Папку `addons` в
проводнике надо будет один раз открыть по новому адресу с тем же логином Samba.

Колонка и телефон дома по-прежнему ходят на 192.168.178.86 — для них ничего не меняется.

## Что после этого можно из любого места

- выкладывать сервер (`python tools/deploy_addon.py`) — останется нажать «Обновить» в HA,
  а интерфейс HA тоже будет открываться по адресу `http://homeassistant:8123`;
- обновлять колонку по воздуху: `python tools/send.py ota` (провод не нужен, кроме первой
  прошивки 0.4.0 — в старых нет обновления по воздуху);
- смотреть журнал и состояние: `send.py "devices; log 30; last"`, спрашивать `ask …`.
