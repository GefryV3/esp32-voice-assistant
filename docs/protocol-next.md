# Контракт новых сообщений (2026-10-20)

Параллельные сессии разрабатывают прошивку и сервер одновременно. Чтобы они сошлись при
слиянии, форматы новых сообщений зафиксированы здесь. Основной протокол: [protocol.md](protocol.md).
Неизвестные `type` и поля получатель молча игнорирует, поэтому порядок выкладки не важен.

## Сервер → колонка

### `task_status`: ход длинной задачи (Claude Code и фоновые агенты)

```json
{"type": "task_status", "state": "working", "label": "Telegram-бот", "pct": 40}
```

- `state`: `idle` (убрать), `working`, `needs_input` (Claude задал вопрос), `needs_permission`
  (ждёт разрешения), `done`, `failed`.
- `label`: до 31 байта UTF-8, что за задача. `pct`: 0..100 или -1 (процент неизвестен).
- Экран: `working`: кольцо прогресса по краю (при -1 бегущая дуга), подпись снизу;
  `needs_input` / `needs_permission`: янтарная пульсация края и метка «Ждёт тебя»;
  `done`: зелёная вспышка, через 4 с гаснет; `failed`: красная. Приоритет ниже звонка и разговора,
  выше часов и сна (сон прерывается на `needs_*`).

### `quiet`: тихий режим («не слушай»)

```json
{"type": "quiet", "on": true}
```

Колонка показывает точку и подпись «Тишина», глаза спокойные (как во сне, но не гаснут). **Микрофон колонки
продолжает слать звук серверу**: сервер сам слушает локально только слова «мага» и «вернись», в Gemini звук
не уходит. Это нужно, чтобы вернуть колонку голосом. Режим снимается сообщением `quiet` с `on: false`
(или `listen_start`). Ночной режим (`night`) сильнее: в нём экран тёмный, точка не рисуется.

### `ble_scan` (сервер → колонка)

```json
{"type": "ble_scan", "on": 1, "uuid": "<32 hex>"}
```

Включить/выключить сканирование BLE-маячка телефона (iBeacon) с заданным UUID. Работает только в BLE-сборке
прошивки (`sdkconfig.ble`), в обычной сообщение молча игнорируется. Подробнее: [room-presence.md](room-presence.md).

Необязательные поля (колонка применяет только присланные, остальное держит по умолчанию из `net/room.cpp`):

| Поле | По умолчанию | Смысл |
|---|---|---|
| `win_ms` | 80 | окно скана (10…500 мс); ночью не меньше 200 |
| `every_s` | 3 | период скана, пока «нет» или состояние не устоялось (1…120 с) |
| `stable_every_s` | 6 | период, когда «здесь» держится больше минуты и последний цикл слышал маячок |
| `night_every_s` | 15 | период ночью (после сообщения `night`) |
| `silence_s` | 90 | не слышно маячка столько секунд (но не меньше 15 периодов скана) — «ушёл» |
| `cal_s` | — | калибровка: столько секунд скан раз в секунду, окно 200 мс, `room` на каждый цикл с полями `raw`, `heard` |

Скан сам встаёт на паузу при слабом Wi-Fi (< −80 дБм), пока играет звук, нет связи с сервером или идёт обновление
прошивки; время паузы не считается молчанием маячка. Пауза дольше 5 минут → `room` с `src: "none"`.

### `light_flash` (необязательно, мост «мама зовёт»)

Не нужен: вспышками света занимается сервер через WLED/HA.

## Колонка → сервер

### `clap`: хлопки

```json
{"type": "clap", "count": 2}
```

Колонка сама распознаёт серию хлопков (на устройстве, без слова пробуждения и без сети).
`count` 2 — переключить весь свет комнаты. Сервер действует по получении.

### `room`: «человек рядом с колонкой»

```json
{"type": "room", "here": true, "rssi": -58, "src": "ble"}
```

Колонка шлёт при смене состояния и раз в 30 с. `src`: `ble` (маячок телефона), `radar`
(датчик присутствия, если будет), `none` (нечем определять). Сервер учитывает это в
`presence.py` как самый сильный признак «в комнате».

Необязательные поля (старый сервер их игнорирует): `heap_free`, `heap_min` — свободная внутренняя RAM колонки и
минимум за всё время работы, байт (диагностика BLE, консоль сервера `room` их показывает); `raw` (RSSI последнего
пакета маячка в цикле) и `heard` (сколько пакетов) — только в режиме калибровки (`cal_s`).

## Колонка без сервера

Колонка сама держит часы, таймер и запланированные сигналы, если связи нет. Сервер заранее
присылает `plan` (может повторять при каждом подключении):

```json
{"type": "plan", "alarms": [{"at": 1760940000, "label": "Подъём"}], "timers": []}
```

`at`: Unix-время. Без связи сигнал звучит встроенным тоном и показывается на экране.
`alarms` — напоминания и будильники, `timers` — таймеры; `label` до 31 байта, не больше 8 в списке.
План каждый раз заменяет предыдущий целиком. Сервер шлёт его при подключении и при любом изменении.

### `config`: пороги BLE

`{"type":"config","ble_near":-72,"ble_far":-80}` — пороги RSSI маячка в дБм: «рядом» выше `ble_near`, «ушёл» ниже
`ble_far` (`ble_far` < `ble_near`). Сервер хранит их (результат `room calibrate apply`) и шлёт при каждом подключении.

### `config`: хлопки

`{"type":"config","clap":1,"clap_sens":5}` — включить/выключить детектор хлопков на колонке и
чувствительность 1…10. Колонка применяет только присланные поля (сон и хлопки приходят отдельно).
