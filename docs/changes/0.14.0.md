# 0.14.0: вторая волна (сводка для CHANGELOG)

Слиты пять работ (подробности в одноимённых файлах рядом):
- **fastpath**: быстрый путь простых команд без Gemini (свет, таймер, «стоп», время; подтверждение тоном), шёпот в ответ.
- **voice-id**: голос хозяина (отпечаток WeSpeaker ONNX), `voice enroll/on/off/any`, «кто в комнате», охрана без записи.
  Режим «слушаю комнату» с согласием семьи НЕ сделан: ждёт прямого подтверждения пользователя в сессии voice-id.
- **school**: домашка, контрольные, замены из WebUntis; копилка уведомлений Teams и Outlook; «помоги запомнить».
- **hunches**: догадки о привычках и автоматизации HA с префиксом «Мага:», откат.
- **extras**: голосовые сообщения Telegram звучат на колонке, `/say`, переводчик на любые языки, новости по темам,
  перерывы по активности компьютера. В образ аддона добавлен ffmpeg.
- Эмоциональный диалог Gemini выключен по умолчанию (Gemini 3.8 Live его убрал).
