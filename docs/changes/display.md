# Экран: задача, игры, глаза (сессия display)

Ветка `claude/display-8a16f1`. Прошивка собрана, **на колонке не проверялась** (прошивать было нельзя).

## Размер и ресурсы
- `jarvis.bin` 0x12d870 = 1 230 960 байт при слоте 0x1c0000 (1.75 МБ): свободно 33 %.
- Новых больших буферов нет, внутренняя RAM почти не тронута (рост — только структуры Input/Scene и состояние анимации, сотни байт; все таблицы остались как были). Свободную RAM и кадры в колонке не мерил: после заливки смотри строку `кадры:` в логе.
- Оценка кадров: покой/разговор прежние (кольцо задачи — одна полоса ring_band; микрофонная часть — несколько умножений на кадр 20 мс). Игры дороже: колесо и кубик считают пиксели по формуле (~10–20 тыс. пикселей), ожидаю 35–50 к/с во время игры, она короткая. Проверить вживую.

## 1. task_status
- Сервер: `protocol.task_status(state, label, pct)` (label ≤31 байт, pct −1…100), консоль `task <state> [pct] [название]`, тесты в `tests/test_protocol.py`.
- Прошивка: разбор в `net/uplink.cpp` → `ui::set_task`; кольцо R=115 по краю: working — доля или бегущая дуга с хвостом (pct −1), needs_* — янтарное пульсирующее кольцо + пульс края + «Ждёт тебя», done — зелёная вспышка, гаснет через 4 с, failed — красная двойная вспышка, гаснет через 6 с. Подпись (label) и статус снизу, глаза уменьшаются, часы прячутся.
- Приоритет: звонок/карточка/разговор/таймер > игра > задача > плеер > часы и сон. needs_* будит из сна; ночной режим задачу скрывает. Во сне working/done/failed видны тонким кольцом без подписи. Пока ждёт тебя — колонка не засыпает.

## 2. Игры и счётчик (#25)
Файл `firmware/main/face/games.inc` (подключён в render.cpp). Сцена по центру, глаза маленькие сверху следят и реагируют (в «камень-ножницы-бумага» радуются/огорчаются).
- coin (подброс с параболой, переворот, тень, «О»/«Р», потом «Орёл/Решка»), dice (кубик с точками крутится и прыгает, грани мелькают, садится), wheel (цветные сектора, вращение с замедлением, указатель сверху, выигравший сектор подсвечен), rps (кулак качается «раз… два… три!», потом значок и исход), magic8 (шар трясётся, «8» сменяется ответом цветом по смыслу), ttt (метки с отскоком, выигрышная линия).
- Счётчик `reminders`: пилюля с колокольчиком и числом под часами.
- Старые длительности из protocol.md сохранены (coin 3.2 с, dice 2.4, wheel 3.4, rps 3.6, magic8 3.6, ttt 45 с).

## 3. Глаза (#26)
- `audio.cpp`: слух считается по микрофону на колонке (звук не уходит): `mic_level()`, `bang_count()` (резкий громкий звук, не считается пока говорит динамик), `beat_count()`.
- Вздрагивание на хлопок/стук (рывок, глаза шире, моргание; во сне глаза приоткрываются).
- Слушание: форма и взгляд следят за реальным уровнем голоса.
- Эмоции: рывки при старте happy/surprise/sorry, ирония (вторая «бровь»), новые `tired` и `bored` (**в серверном `EMOTIONS` их нет — добавить при слиянии**, прошивка понимает), самопроизвольная скука при долгом бездействии и усталость после 23:00.
- Микровзгляды (±2 px), быстрый взгляд вбок и назад, неровное моргание, двойное, моргание на резком повороте, медленное когда устал.
- Зевок перед сном (в Drowsy).
- Музыка (`player` playing): подпрыгивание на удары (микрофон слышит ритм, иначе ровный ~107 уд/мин) и моргание каждый 4-й.
