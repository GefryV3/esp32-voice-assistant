## 1. Быстрый путь (`server/jarvis/fastpath.py`)

После слова пробуждения звук идёт и в Gemini, и в локальный Vosk с грамматикой из слов-команд (малый словарь,
числа словами: «пять, пятнадцать, двадцать пять, сто двадцать, полчаса, четверть часа, час»). Команда
срабатывает, только если выполнены ВСЕ условия: Vosk выдал законченную фразу (по паузе, не частичный
результат), уверенность каждого слова ≥ 0.7, в фразе нет `[unk]`, вся фраза (без хвоста «мага» в начале и
«пожалуйста» в конце) точно равна одной из команд, Gemini ещё не начал отвечать/звать функции. Иначе фраза идёт
в Gemini как раньше. Выбор «только законченный результат»: частичный быстрее, но «включи свет… (пауза) …в
коридоре» сработал бы на половине.

Команды: свет комнаты (включи/выключи/потемнее/поярче/«всё выключи», через новый `Lights.room()` на
существующих `lightstate`/HA), таймер («таймер на N минут/секунд/час/полчаса», «отмени таймер», через
`brain.set_timer`), «стоп/тихо/замолчи/хватит/перестань», «который час», «сколько до будильника» (из
`bridge.phone_state.next_alarm`), «отвечай на команды вслух/молча». Список расширяется таблицей `PHRASES` и
веткой в `FastPath.execute`.

Подтверждение: по умолчанию короткий тон 1175 Гц (70 мс) + мимика `happy` + подпись на экране, без голоса.
Голосом «Готово» (отдельным коротким разговором по тексту через Gemini, после закрытия основного) говорим
только для таймеров и при ошибке («не нашёл ни одной лампы»). Время и будильник в режиме off — только подпись.
Журнал: строка `быстрый путь: «…» (вид) выполнено за N мс после слова пробуждения`, консоль `fast log`.

Настройки (prefs в SQLite, переживают перезапуск): `fastpath` on/off (по умолчанию on, если есть модель),
`fastpath_voice` off|short|full (по умолчанию off). Консоль: `fast on|off|status|log`, `fast voice off|short|full`.
Голосом: «отвечай на команды вслух» (short) / «молча» (off). В немецком и играх быстрый путь выключен.

## 2. Шёпот (`server/jarvis/whisper.py`)

Признак по PCM (16 кГц, кадры 40 мс): средний уровень активных кадров ниже порога (по умолчанию −36 дБFS)
И не больше 25% кадров с основным тоном (нормированная автокорреляция на 50–400 Гц > 0.5). Решение один раз
на разговор, после ~0.5 с речи. При шёпоте: громкость динамика = 25% дневной (не ниже 5, не громче ночной),
после разговора возвращается; Gemini получает заметку `WHISPER_NOTE` («отвечай шёпотом, одной короткой фразой»)
через `LiveSession.send_note` (clientContent с turnComplete=false). Консоль: `whisper on|off|status|<дБFS>`
(по умолчанию вкл). В журнал пишется статистика («средний уровень … звонких кадров …») — по ней подбирать порог.

## Затронутые общие файлы (аддитивно)

`voice.py` (слушатели в `Conversation`, событие `fast`, `whisper_mode`, `fast_factory`, команды консоли,
голосовое подтверждение после разговора), `lights.py` (`room()`), `gemini_live.py` (`send_note`), `character.py`
(`WHISPER_NOTE`), `__main__.py` (фабрика быстрого пути). Новые модули: `fastpath.py`, `whisper.py`.
Новых переменных `.env` нет. Модель Vosk та же, что у слова пробуждения (уже скачивается).

## Проверить вживую

- Vosk с этой грамматикой: узнаёт ли команды в реальной комнате и как часто путает чужую речь (порог
  уверенности `MIN_CONF` = 0.7 не подбирался). Смотреть журнал и `fast log`.
- Задержка: сколько мс до выполнения против 0.6–0.8 с у Gemini; успевает ли Vosk-конец фразы раньше Gemini.
- Голосовое «Готово» после таймера идёт по новой сессии Gemini по тексту (~1–2 с): медленнее самой команды.
- Шёпот: реальные значения «средний уровень / звонких кадров» для шёпота и обычной речи, подстроить `whisper <дБFS>`.
- Принимает ли выбранная Live-модель `clientContent` с `turnComplete=false` посреди сессии (иначе заметка не
  сработает, останется только понижение громкости; в журнале будет предупреждение).
- `Lights.room("dim"/"bright")` использует `brightness_step_pct` ±25 через HA на включённых лампах комнаты.

## Осталось

- Частичные результаты Vosk (ещё быстрее) сознательно не использованы; можно добавить при уверенности в точности.
- Команды с названием лампы/комнаты («выключи свет на кухне») уходят в Gemini.
